# Reporting Security Vulnerabilities

**If you believe you have discovered a security issue within Brio, please report it responsibly.** 

We take security seriously and appreciate your efforts to responsibly disclose any vulnerabilities you find.

## How to Report

Please report security vulnerabilities by:

1. Opening a new private security vulnerability report through GitHub Security Advisories (if available)
2. Or by contacting the Brio security team directly via our issue tracker with a "Security" label

## Responsible Disclosure

Brio values the members of the independent security research community who find security vulnerabilities and work
with our team so that proper fixes can be issued to users. Our policy is to credit all researchers in the fix's release
notes. In order to receive credit, security researchers must follow responsible disclosure practices, including:

- They do not publish the vulnerability prior to the Brio team releasing a fix for it
- They do not divulge exact details of the issue, for example, through exploits or proof-of-concepts

## What to Include

When reporting a vulnerability, please include:

- A clear description of the issue
- Steps to reproduce the vulnerability
- Potential impact of the vulnerability
- Any suggested fixes or mitigations (optional)

We will acknowledge your report and work with you to understand and address the issue promptly.

---

**Note:** Brio is a fork of Directus v9.26.0 (GPL-3.0). For security issues specific to the original Directus codebase,
you may also want to report to the Directus team at https://github.com/directus/directus/security
